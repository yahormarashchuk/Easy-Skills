# Easy Skills v0.1.0-alpha.1

First public alpha of the local engineering workflow runner and its 13 installable
skills for Codex CLI and Claude Code. This is a prerelease for evaluation; the complete
v1 acceptance scenario remains outstanding.

## Included

- TypeScript runner on Node.js 24+, SQLite persistence, event history, process and
  resource locks, detached execution, recovery guards and exact-session continuation.
- Explicit provider/model assignments and approval of the exact plan version;
  read-only planning through the selected PLAN client and model.
- Sequential dependent tasks within a feature, parallel features in separate worktrees,
  per-task PRs, a final feature PR, revision-bound checks and independent review sessions.
- Branch synchronization, conflict recovery, safe cleanup after confirmed final merge,
  SMTP notifications and scoped GitHub control and decision commands.
- English documentation, templates and skills; Apache-2.0 licensing with retained
  notices and pinned provenance for adapted procedures.

## Install

Install Node.js 24+, Git, GitHub CLI and the official AI clients you intend to use.
Authenticate with your own accounts, then install the compiled package:

```sh
npm install -g https://github.com/yahormarashchuk/Easy-Skills/releases/download/v0.1.0-alpha.1/easy-skills-0.1.0-alpha.1.tgz
easy-skills doctor
easy-skills install-skills --client codex
```

Use `--client claude-code` for Claude Code skills. Review the installation proposal
and repeat with its `--apply-hash HASH` value. See the repository README for project
setup and the feature workflow. No separate server, mandatory WSL, Docker or model
API key is required. Model usage is billed under the user's own client account.

The attached `.tgz` includes compiled JavaScript, schemas, skills and documentation.
`SHA256SUMS` records its SHA-256 digest. GitHub's source archives contain source code
and require `npm ci` followed by `npm run build`. This release does not publish the
package to the npm registry.

## Validation

The local Windows test suite passed all 23 tests, including parallel feature execution,
quota recovery, detached worker lifecycle, lost PR-create responses, conflict recovery,
stale decisions and conservative cleanup. TypeScript, package build, installation from
the tarball and all 13 skill validations passed.

Real read-only execution and exact-session resume also passed with:

- Codex CLI 0.163.0, `gpt-6.1-sol`, using saved ChatGPT login.
- Claude Code 2.1.306, `claude-sonnet-5-5`, using claude.ai login.

These probes verify two small turns per client, not a complete autonomous feature.

Hosted CI is unverified for this prerelease. The Windows/Linux workflow is committed
and Actions is enabled, but GitHub has not registered the workflow or created a run;
manual dispatch returns HTTP 404. The test results above are from local Windows
validation. Follow subsequent runs in GitHub Actions when the workflow is registered.

## Known limits

- Full real-provider/GitHub/SMTP acceptance and clean-machine installation remain to
  be completed. GitHub integration currently uses gh; GitHub MCP transport is not implemented.
- Automated updates, rollback management and startup after reboot are not implemented.
  The computer must stay on and awake for local execution.
- Environment support inspects Compose configuration and locks shared resources;
  it does not provision feature-specific databases, schemas or ports automatically.
- Cleanup retains branches and never deletes database contents or Docker volumes.
  It rejects dirty, untracked or ignored files, including dependency directories.
- Windows batch launchers support ordinary arguments and spaced paths. For literal
  shell metacharacters, invoke a native executable or a Node.js script directly.

See `docs/implementation-status.md`, `SECURITY.md` and `THIRD_PARTY_NOTICES.md` for the
complete implementation boundaries, host-access model and attribution.
