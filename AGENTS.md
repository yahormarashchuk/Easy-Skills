# Easy Skills

TypeScript/Node.js 24+, SQLite outside managed repositories. Run `npm run check`,
`npm test`, and `npm run build` after changing executable behavior.

Keep all maintained documentation, instructions, comments, examples, templates and
generated user-facing text in English. Use language-neutral data for Unicode tests.

Preserve explicit provider/model assignments, revision-bound approvals and evidence,
one issue executor per feature, recoverable external operations, and clean-worktree
guards. Never treat model prose as evidence of a passing deterministic check.
Do not put subscription sessions or secrets in tests, fixtures, or public CI.

See `docs/architecture/runner.md` and `docs/implementation-status.md` for the current
contracts and verified limits. Keep compatibility claims tied to actual observations.
